# GlowMart Frontend

Frontend toko skincare online pakai HTML, CSS, Vanilla JS.

## Cara Jalanin
1. Install Live Server di VS Code
2. Klik kanan `index.html` > Open with Live Server
3. Pastikan backend jalan di `http://localhost:5000`

## Struktur
- `/css` : styling
- `/js` : logika frontend
- `/assets` : gambar

## Deploy
Push ke GitHub, lalu connect ke Vercel untuk auto deploy.
